2. テンプレート読み込み関数（ファイルを呼び出す）

🔗 テンプレート読み込み関数の役割

他のファイルを読み込んで、テンプレートを分割して管理するための関数です。

2.1 基本的なテンプレート読み込み

📁 Twenty Seventeenの実際のコード例を確認してみよう

Localでindex.phpを開いて、以下のコードを探してください：

<?php get_header(); ?>

<div class="wrap">
    <!-- ページの内容 -->
</div>

<?php get_footer(); ?>
関数 役割 読み込まれるファイル
get_header() ヘッダー部分を読み込み header.php
get_footer() フッター部分を読み込み footer.php
get_sidebar() サイドバーを読み込み sidebar.php

2.2 引数を使った応用

<?php get_header('custom'); ?>  // header-custom.php を読み込み
<?php get_sidebar('shop'); ?>   // sidebar-shop.php を読み込み

2.3 テンプレートパーツの読み込み

📁 Twenty Seventeenで実際に使われている例を確認

index.phpやfooter.phpで以下のようなコードを探してみてください：

// index.php から
get_template_part( 'template-parts/post/content', get_post_format() );

// footer.php から
get_template_part( 'template-parts/footer/footer', 'widgets' );
get_template_part( 'template-parts/footer/site', 'info' );
get_template_part() の仕組み：
get_template_part( 'フォルダ/ファイル名', '追加部分' );
結果：フォルダ/ファイル名-追加部分.php が読み込まれる

✅ テンプレート読み込み関数 確認チェックリスト

  • Twenty Seventeenのindex.phpでget_header()を見つけた
  • get_footer()の位置を確認した
  • get_template_part()がどのファイルで使われているか確認した
  • template-partsフォルダの中身を確認した

3. 条件分岐関数（「もし〜なら」の判定）

🔀 条件分岐関数の役割

「もしブログページなら」「もしアイキャッチ画像があるなら」といった条件に応じて表示を切り替える関数です。

参考： Conditional Tags（WordPress公式ドキュメント）

3.1 基本的な考え方

  • 「もしブログページなら、タイトルを表示」
  • 「もしアイキャッチ画像があるなら、画像を表示」
  • 「もしメニューが設定されていたら、ナビゲーションを表示」

3.2 ページの種類を判定

📁 Twenty Seventeenの実際の使用例を確認

index.phpで以下のようなコードを探してみてください：

<?php if ( is_home() && ! is_front_page() ) : ?>
    <header class="page-header">
        <h1 class="page-title"><?php single_post_title(); ?></h1>
    </header>
<?php else : ?>
    <header class="page-header">
        <h2 class="page-title"><?php _e( 'Posts', 'twentyseventeen' ); ?></h2>
    </header>
<?php endif; ?>
関数 判定内容 使用場面
is_home() ブログのホームページか ブログ一覧ページでのみ特別な表示
is_front_page() サイトのトップページか フロントページ専用のヘッダー表示
is_single() 投稿の個別ページか 記事ページでのみコメント欄表示
is_page() 固定ページか 固定ページでのみサイドバー非表示
is_category() カテゴリーページか カテゴリー説明文の表示
is_404() 404エラーページか エラーメッセージの表示

3.3 コンテンツの存在を判定

📁 Twenty Seventeenのheader.phpとfooter.phpで確認

以下のようなコードを探してみてください：

// header.php から
<?php if ( has_post_thumbnail() ) : ?>
    <div class="featured-image">
        <?php the_post_thumbnail(); ?>
    </div>
<?php endif; ?>

// footer.php から
<?php if ( has_nav_menu( 'social' ) ) : ?>
    <nav class="social-navigation">
        <?php wp_nav_menu( array( 'theme_location' => 'social' ) ); ?>
    </nav>
<?php endif; ?>
関数 判定内容 使用場面
has_post_thumbnail() アイキャッチ画像があるか 画像がある場合のみ表示
has_nav_menu() メニューが設定されているか メニューがある場合のみナビゲーション表示
is_active_sidebar() ウィジェットが設定されているか サイドバーに内容がある場合のみ表示
💡 条件分岐のコツ
・is = 「〜ですか？」
・has = 「〜を持っていますか？」
・&& = 「かつ」
・! = 「ではない」

✅ 条件分岐関数 確認チェックリスト

  • Show Current Templateプラグインで現在のページがhome, page, singleのどれか確認した
  • Twenty Seventeenのindex.phpで条件分岐を見つけた
  • header.phpでhas_post_thumbnail()を見つけた
  • footer.phpでhas_nav_menu()を見つけた

4. ループ関数（複数の投稿を処理）

🔄 ループ関数の役割

複数の投稿を順番に処理して表示するための関数です。ブログ一覧ページなどで使用されます。

参考： The Loop（WordPress公式ドキュメント）

4.1 WordPressループの基本構造

📁 Twenty Seventeenの実際のコードを確認

index.phpで以下のようなコードを探してみてください：

<?php
if ( have_posts() ) :
    // Start the Loop.
    while ( have_posts() ) :
        the_post();
        
        get_template_part( 'template-parts/post/content', get_post_format() );
        
    endwhile;
    
    the_posts_pagination();
else :
    get_template_part( 'template-parts/post/content', 'none' );
endif;
?>

4.2 ループ関数の役割

関数 役割 詳細
have_posts() 投稿があるかチェック true/false を返す
the_post() 次の投稿データをセットアップ 投稿情報をグローバル変数に設定
the_posts_pagination() ページネーション表示 「前へ」「次へ」リンクを生成

4.3 ループの流れを理解しよう

🔄 ループの動作

  1. have_posts() で「投稿はありますか？」とチェック
  2. while で「投稿がある限り繰り返し」
  3. the_post() で「次の投稿データを準備」
  4. 投稿の情報を表示（タイトル、本文など）
  5. 2に戻って次の投稿へ

4.4 ループ内で使える関数

⚠️ 重要：以下の関数はループ内（the_post() の後）でのみ使用可能 
while ( have_posts() ) :
    the_post();
    
    // ここで以下の関数が使える
    the_title();        // タイトル表示
    the_content();      // 本文表示
    the_excerpt();      // 抜粋表示
    the_date();         // 投稿日表示
    the_permalink();    // リンク表示
    
endwhile;

✅ ループ関数 確認チェックリスト

  • index.phpでhave_posts()を見つけた
  • while文を見つけた
  • the_post()の位置を確認した
  • ブログ一覧ページでループが動作していることを確認した

5. コンテンツ出力関数（データベースから情報を取得・表示）

📤 コンテンツ出力関数の役割

データベースから投稿の情報やサイトの情報を取得して表示する関数です。

参考： Template Tags（WordPress公式ドキュメント）

5.1 the_ と get_ の違い

📁 Twenty Seventeenの実際の使用例を確認

template-parts/post/content.phpで以下のようなコードを探してみてください：

// template-parts/post/content.php から（一部省略）
if ( is_single() ) {
    the_title( '<h1 class="entry-title">', '</h1>' );  // the_ : そのまま画面に出力
} else {
    // the_title() が画面に出力する文字列の中に、get_permalink() で受け取ったURLを組み込む
    the_title( '<h2 class="entry-title"><a href="' . esc_url( get_permalink() ) . '" rel="bookmark">', '</a></h2>' );
}
💡 ポイント
・the_title() → 画面に出力するのが目的なので the_ を使う
・get_permalink() → 文字列の材料として使い、esc_url() で加工もするので get_ を使う
・「そのまま表示したい」なら the_、「受け取って加工・組み込みたい」なら get_
the_ 関数 get_ 関数 違い
the_title() get_the_title() the_は直接出力 / get_は値を返す
the_content() get_the_content() 同上
the_date() get_the_date() 同上
the_permalink() get_permalink() 同上

5.2 使い分けの例

直接表示したい場合

<h1><?php the_title(); ?></h1>

加工してから表示したい場合

<?php 
$title = get_the_title();
$title = '【新着】' . $title;
echo $title;
?>

5.3 投稿情報を取得する関数

関数 取得内容 使用例
the_title() 投稿タイトル <h2><?php the_title(); ?></h2>
the_content() 投稿本文 <div><?php the_content(); ?></div>
the_excerpt() 投稿抜粋 <p><?php the_excerpt(); ?></p>
the_date() 投稿日 <time><?php the_date(); ?></time>
the_time() 投稿時刻 <time><?php the_time('H:i'); ?></time>
the_author() 投稿者名 <span><?php the_author(); ?></span>

5.4 サイト情報を取得する関数

📁 Twenty Seventeenのheader.phpで確認

以下のようなコードを探してみてください：

<meta charset="<?php bloginfo( 'charset' ); ?>">
<html <?php language_attributes(); ?> class="no-js no-svg">
<body <?php body_class(); ?>>
関数 取得内容 結果例
bloginfo('name') サイト名 「私のブログ」
bloginfo('description') サイトの説明 「日々の出来事を綴るブログ」
bloginfo('charset') 文字コード 「UTF-8」
language_attributes() 言語属性 lang="ja"
body_class() bodyタグのクラス class="home blog"

5.5 必須関数（必ず入れる関数）

📁 Twenty Seventeenのheader.phpとfooter.phpで確認

以下のコードを探してみてください：

<!-- header.php の <head> 内 -->
<?php wp_head(); ?>
</head>

<!-- footer.php の </body> 前 -->
<?php wp_footer(); ?>
</body>
関数 役割 重要度
wp_head() ヘッダー情報を出力 ★★★ 必須
wp_footer() フッター情報を出力 ★★★ 必須
💡 なぜ必須なの？
・wp_head() → CSS、JavaScript、SEO情報などを自動出力
・wp_footer() → プラグインのスクリプトなどを自動出力
・これらがないとWordPressが正常に動作しない

✅ コンテンツ出力関数 確認チェックリスト

  • header.phpでwp_head()を見つけた
  • footer.phpでwp_footer()を見つけた
  • bloginfo('charset')の使用例を確認した
  • the_title()とget_the_title()の違いを理解した

6. 実践演習:学んだ関数でpage.phpを編集してみよう

⚠️ 作業前の準備
前回の授業でテンプレートファイルをいろいろ編集して、元の状態がわからなくなっている方もいると思います。
まずは新しいテーマファイルをダウンロードして入れ替えましょう。

6.1 準備作業

📝 ステップ1:Twenty Seventeenテーマの再ダウンロード

  1. WordPress公式サイトからTwenty Seventeenをダウンロード
  2. ダウンロードしたZIPファイルを解凍
  3. Localのサイトフォルダを開く（Local Sites/サイト名/app/public/wp-content/themes/）
  4. 既存の twentyseventeen フォルダを削除または別名に変更
  5. 新しくダウンロードした twentyseventeen フォルダをコピー

📝 ステップ2:page.phpをバックアップ

  1. wp-content/themes/twentyseventeen/page.php を開く
  2. page.phpをコピーして page_backup.php として保存
  3. 万が一問題が起きた時は、page_backup.phpの内容をpage.phpにコピーして戻せます

6.2 条件分岐を追加してみよう

💡 今回の演習のポイント
特定のページ（スラッグが「about」のページ）でのみ、特別なヘッダー部分を表示する条件分岐を追加します。
これにより、ページによって表示内容を変えることができる仕組みを体験できます。

📝 ステップ3:page.phpを編集

page.phpの <?php get_header(); ?> の直後に、以下のコードを追加してください:

<?php get_header(); ?>

<!-- ↓↓↓ ここから追加 ↓↓↓ -->
<!-- 条件分岐:特定ページでのみ特別なヘッダー -->
<?php if ( is_page( 'about' ) ) : ?>
    <div class="about-hero" style="background: #3498db; color: white; padding: 40px; text-align: center; margin-bottom: 20px;">
        <h1 style="margin: 0 0 10px 0;">私たちについて</h1>
        <p style="margin: 0;">会社の理念をご紹介します</p>
    </div>
<?php endif; ?>
<!-- ↑↑↑ ここまで追加 ↑↑↑ -->

<div class="wrap">
    <!-- 以下は元のコードのまま -->

📝 ステップ4:動作確認

  1. 「about」ページを表示して、青い背景のヘッダーが表示されることを確認
  2. 他のページ（今回だとSample Pageくらいしかないですが）では表示されないことを確認
💡 このコードの仕組み
・is_page( 'about' ) = 「スラッグが'about'のページかどうか」を判定
・条件が true（真）の場合のみ、<div class="about-hero"> 以下が表示される
・他のページでは条件が false（偽）なので、何も表示されない

このように条件分岐を使うことで、ページごとに異なる表示を実現できます。
⚠️ エラーが出た場合
・画面が真っ白になった → バックアップファイルから復元
・表示が崩れた → HTMLタグの閉じ忘れがないか確認（特に <?php endif; ?>）
・青いヘッダーが表示されない → ページのスラッグが「about」になっているか確認

7. まとめ：4つの関数カテゴリー

カテゴリー 主な役割 代表的な関数
テンプレート読み込み ファイルを呼び出す get_header(), get_footer(), get_template_part()
条件分岐 「もし〜なら」の判定 is_home(), is_page(), has_post_thumbnail()
ループ 複数投稿の処理 have_posts(), the_post(), while
コンテンツ出力 データ取得・表示 the_title(), the_content(), bloginfo()

テンプレート制作でよく使う4つのカテゴリの関数を知ることができました。
全部覚える必要はありません。代表的な関数を覚えて、必要な時に調べる習慣をつけましょう。
