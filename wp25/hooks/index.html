メニュー・ウィジェット・フック

テーマでのナビゲーションメニューの構築

管理画面で「メニュー」を設定したことがありますね。今回は、そのメニューをテーマ側でどう実装するかを学びます。

メニューの仕組み（全体像）

① functions.phpでメニューの場所を登録 ↓ ② 管理画面で「メニュー」を作成し、登録した場所に割り当て ↓ ③ テンプレートファイル（header.phpなど）でメニューを表示

① functions.phpでメニューを登録する

Twenty Seventeenの functions.php を開いて、twentyseventeen_setup() 関数内の以下のコードを探してください：

function twentyseventeen_setup() {
    // 〜省略〜

    // This theme uses wp_nav_menu() in two locations.
    register_nav_menus(
        array(
            'top'    => __( 'Top Menu', 'twentyseventeen' ),
            'social' => __( 'Social Links Menu', 'twentyseventeen' ),
        )
    );

    // 〜省略〜
}
add_action( 'after_setup_theme', 'twentyseventeen_setup' );

コードの解説

register_nav_menus()

  • メニューを配置できる「場所」を登録する関数
  • 配列で複数の場所を一度に登録できる
📚 公式リファレンス: register_nav_menus() | Navigation Menus 
register_nav_menus( array(
    'メニューのID' => '管理画面に表示される名前',
) );

Twenty Seventeenでは：

  • 'top' → トップメニュー（ヘッダーのナビゲーション）
  • 'social' → ソーシャルリンクメニュー（SNSアイコン用）

の2箇所を登録しています。

__( 'Top Menu', 'twentyseventeen' ) について

  • これは翻訳関数です
  • 翻訳ファイルがあれば、日本語環境では「トップメニュー」のように翻訳されて表示されます

add_action( 'after_setup_theme', 'twentyseventeen_setup' )

  • after_setup_theme というタイミング（フック）で関数を実行
  • テーマの初期設定はこのタイミングで行う

② 管理画面での確認

Local で管理画面を開き、「外観」→「メニュー」を見てください。

画面下部の「メニュー設定」に以下が表示されているはずです：

  • ☑ トップメニュー
  • ☑ ソーシャルリンクメニュー

これが functions.php で登録した場所です！

③ テンプレートファイルでメニューを表示する

Twenty Seventeenの header.php を開いて、以下のコードを探してください：

<div class="navigation-top">
    <div class="wrap">
        <?php get_template_part( 'template-parts/navigation/navigation', 'top' ); ?>
    </div>
</div>

さらに template-parts/navigation/navigation-top.php を開いてください：

<nav id="site-navigation" class="main-navigation" aria-label="<?php esc_attr_e( 'Top Menu', 'twentyseventeen' ); ?>">
    <button class="menu-toggle" aria-controls="top-menu" aria-expanded="false">
        <?php
        echo twentyseventeen_get_svg( array( 'icon' => 'bars' ) );
        echo twentyseventeen_get_svg( array( 'icon' => 'close' ) );
        _e( 'Menu', 'twentyseventeen' );
        ?>
    </button>

    <?php
    wp_nav_menu(
        array(
            'theme_location' => 'top',
            'menu_id'        => 'top-menu',
        )
    );
    ?>

    <?php if ( ( twentyseventeen_is_frontpage() || ( is_home() && is_front_page() ) ) && has_custom_header() ) : ?>
        <!-- 省略：スクロールダウンボタン -->
    <?php endif; ?>
</nav>

コードの解説

重要なのはこの部分：

<?php
wp_nav_menu(
    array(
        'theme_location' => 'top',
        'menu_id'        => 'top-menu',
    )
);
?>

wp_nav_menu()

  • 登録したメニューを表示する関数
  • 配列で様々なオプションを指定できる
📚 公式リファレンス: wp_nav_menu()

主なパラメータ：

パラメータ 意味 例
theme_location どの場所のメニューを表示するか（必須） 'top'
menu_id メニューのul要素に付けるID 'top-menu'
menu_class メニューのul要素に付けるクラス 'main-menu'
container メニューを囲む要素 'nav' / false
container_class 囲む要素のクラス 'menu-container'

出力されるHTML：

<nav id="site-navigation" class="main-navigation">
    <div class="menu-トップメニュー-container">
        <ul id="top-menu" class="menu">
            <li><a href="#">ホーム</a></li>
            <li><a href="#">会社概要</a></li>
            <li><a href="#">お問い合わせ</a></li>
        </ul>
    </div>
</nav>

メニューの流れまとめ

functions.php ↓ register_nav_menus( array( 'top' => 'トップメニュー' ) ); （メニューの場所を登録） ↓ 管理画面「外観」→「メニュー」 （メニューを作成して、「トップメニュー」に割り当て） ↓ navigation-top.php ↓ wp_nav_menu( array( 'theme_location' => 'top' ) ); （登録した場所のメニューを表示）
ポイント：
  • register_nav_menus() で登録した 'top' というID
  • wp_nav_menu() で指定する 'theme_location' => 'top'
  • この2つが一致することで、メニューが表示される

テーマでのウィジェットエリアの構築

管理画面で「ウィジェット」を追加したことがありますね。今回は、そのウィジェットエリアをテーマ側でどう実装するかを学びます。

ウィジェットエリアの仕組み（全体像）

① functions.phpでウィジェットエリアを登録 ↓ ② 管理画面で「ウィジェット」を追加し、エリアに配置 ↓ ③ テンプレートファイル（sidebar.phpなど）でウィジェットを表示

① functions.phpでウィジェットエリアを登録する

Twenty Seventeenの functions.php を開いて、twentyseventeen_widgets_init() 関数を探してください：

function twentyseventeen_widgets_init() {
    register_sidebar(
        array(
            'name'          => __( 'Blog Sidebar', 'twentyseventeen' ),
            'id'            => 'sidebar-1',
            'description'   => __( 'Add widgets here to appear in your sidebar on blog posts and archive pages.', 'twentyseventeen' ),
            'before_widget' => '<section id="%1$s" class="widget %2$s">',
            'after_widget'  => '</section>',
            'before_title'  => '<h2 class="widget-title">',
            'after_title'   => '</h2>',
        )
    );

    register_sidebar(
        array(
            'name'          => __( 'Footer 1', 'twentyseventeen' ),
            'id'            => 'sidebar-2',
            'description'   => __( 'Add widgets here to appear in your footer.', 'twentyseventeen' ),
            'before_widget' => '<section id="%1$s" class="widget %2$s">',
            'after_widget'  => '</section>',
            'before_title'  => '<h2 class="widget-title">',
            'after_title'   => '</h2>',
        )
    );

    register_sidebar(
        array(
            'name'          => __( 'Footer 2', 'twentyseventeen' ),
            'id'            => 'sidebar-3',
            'description'   => __( 'Add widgets here to appear in your footer.', 'twentyseventeen' ),
            'before_widget' => '<section id="%1$s" class="widget %2$s">',
            'after_widget'  => '</section>',
            'before_title'  => '<h2 class="widget-title">',
            'after_title'   => '</h2>',
        )
    );
}
add_action( 'widgets_init', 'twentyseventeen_widgets_init' );

コードの解説

register_sidebar()

  • ウィジェットエリアを登録する関数
  • 「サイドバー」という名前だが、フッターなどにも使える
  • Twenty Seventeenでは3つのウィジェットエリアを登録
📚 公式リファレンス: register_sidebar() | Sidebars

主なパラメータ：

パラメータ 意味 例
name 管理画面に表示される名前 'ブログサイドバー'
id ウィジェットエリアのID（必須・重複不可） 'sidebar-1'
description 管理画面での説明文 'サイドバーに表示されます'
before_widget 各ウィジェットの前に出力するHTML '<section id="%1$s" class="widget %2$s">'
after_widget 各ウィジェットの後に出力するHTML '</section>'
before_title ウィジェットタイトルの前 '<h2 class="widget-title">'
after_title ウィジェットタイトルの後 '</h2>'
%1$s と %2$s について：
  • %1$s → ウィジェット固有のID（例：search-2）
  • %2$s → ウィジェットのクラス（例：widget_search）
  • これらは自動的に置き換えられます

add_action( 'widgets_init', '関数名' )

  • ウィジェット初期化のタイミングで実行

② 管理画面での確認

Local で管理画面を開き、「外観」→「ウィジェット」を見てください。

左側に以下のエリアが表示されているはずです：

  • ブログサイドバー
  • フッター1
  • フッター2

これが functions.php で登録した3つのウィジェットエリアです！

③ テンプレートファイルでウィジェットを表示する

サイドバーの表示

Twenty Seventeenの sidebar.php を開いてください：

?>

コードの解説

is_active_sidebar( 'ウィジェットエリアID' )

  • 指定したウィジェットエリアにウィジェットが配置されているか確認

フック（Hooks）

メニューとウィジェットの資料で、こんなコードを見ましたね：

add_action( 'after_setup_theme', 'twentyseventeen_setup' );
add_action( 'widgets_init', 'twentyseventeen_widgets_init' );

この add_action がフックの仕組みです。今回は、このフックについて学びます。

フックとは何か

フック = WordPressの「決まったタイミング」に、自分の処理を追加する仕組み

WordPressは、ページを表示するまでに決まった順序で処理を実行します。その処理の中に「ここで追加の処理ができますよ」というフックポイントが用意されています。

WordPressの処理の流れ ↓ テーマを読み込む　←ここで追加処理できる（after_setup_themeフック） ↓ ウィジェットを初期化　←ここで追加処理できる（widgets_initフック） ↓ CSS/JSを読み込む　←ここで追加処理できる（wp_enqueue_scriptsフック） ↓ ヘッダーを出力　←ここで追加処理できる（wp_headフック） ↓ コンテンツを出力 ↓ フッターを出力　←ここで追加処理できる（wp_footerフック）

フックにはアクションフックとフィルターフックの2種類があります。

📚 公式リファレンス: Hooks | Actions | Filters

アクションフック（Action Hooks）

「決まったタイミング」で処理を実行する

基本の書き方

function 自分で作る関数名() {
    // 実行したい処理
}
add_action( 'フックの名前', '自分で作る関数名' );
📚 公式リファレンス: add_action()

① すでに見たアクションフック

Twenty Seventeenの functions.php で見た例を振り返ります。

after_setup_theme - テーマ機能の登録

function twentyseventeen_setup() {
    // メニューの登録
    register_nav_menus( array(
        'top'    => __( 'Top Menu', 'twentyseventeen' ),
        'social' => __( 'Social Links Menu', 'twentyseventeen' ),
    ) );
    
    // アイキャッチ画像のサポート
    add_theme_support( 'post-thumbnails' );
    
    // その他のテーマ機能の登録
}
add_action( 'after_setup_theme', 'twentyseventeen_setup' );

タイミング： WordPressがテーマを読み込んだ直後
用途： テーマの機能（メニュー、アイキャッチ画像など）を登録

widgets_init - ウィジェットエリアの登録

function twentyseventeen_widgets_init() {
    register_sidebar( array(
        'name' => __( 'Blog Sidebar', 'twentyseventeen' ),
        'id'   => 'sidebar-1',
        // 省略
    ) );
}
add_action( 'widgets_init', 'twentyseventeen_widgets_init' );

タイミング： WordPressがウィジェットを初期化するとき
用途： ウィジェットエリアを登録

② その他の重要なアクションフック

Twenty Seventeenの functions.php から他の例も見てみましょう。

wp_enqueue_scripts - CSS/JavaScriptの読み込み

functions.php の twentyseventeen_scripts() 関数を探してください：

function twentyseventeen_scripts() {
    // CSSの読み込み
    wp_enqueue_style( 'twentyseventeen-style', get_stylesheet_uri() );
    
    // JavaScriptの読み込み
    wp_enqueue_script( 'twentyseventeen-global', get_theme_file_uri( '/assets/js/global.js' ), array( 'jquery' ) );
}
add_action( 'wp_enqueue_scripts', 'twentyseventeen_scripts' );

タイミング： CSS/JavaScriptを読み込むとき
用途： テーマ独自のCSS/JavaScriptファイルを読み込む

重要： CSS/JSは必ずこのフックで読み込む（直接 <link> や <script> タグを書かない）

wp_head - headタグ内に出力

functions.php の twentyseventeen_javascript_detection() 関数を探してください：

function twentyseventeen_javascript_detection() {
    echo "<script>(function(html){html.className = html.className.replace(/\bno-js\b/,'js')})(document.documentElement);</script>\n";
}
add_action( 'wp_head', 'twentyseventeen_javascript_detection', 0 );

タイミング： </head> の直前
用途： headタグ内に独自のコードを追加

注意： header.php に <?php wp_head(); ?> がないとこのフックは動作しない

wp_footer - bodyタグの終了直前に出力

タイミング： </body> の直前
用途： フッター部分に独自のコードを追加

注意： footer.php に <?php wp_footer(); ?> がないとこのフックは動作しない

主なアクションフック一覧

フック名 タイミング 用途
after_setup_theme テーマ読み込み後 テーマ機能の登録
init WordPress初期化時 カスタム投稿タイプなどの登録
widgets_init ウィジェット初期化時 ウィジェットエリアの登録
wp_enqueue_scripts CSS/JS読み込み時 スタイルシート・スクリプトの読み込み
wp_head </head> の直前 headタグ内に追加コード
wp_footer </body> の直前 フッターに追加コード

フィルターフック（Filter Hooks）

データを受け取って、変更して返す

アクションフックが「処理を追加」するのに対して、フィルターフックは「データを変更」します。

基本の書き方

function 自分で作る関数名( $data ) {
    // $dataを変更
    return $data; // 変更したデータを返す
}
add_filter( 'フィルターの名前', '自分で作る関数名' );
📚 公式リファレンス: add_filter()

① Twenty Seventeenでの実例

functions.php の twentyseventeen_excerpt_more() 関数を探してください：

function twentyseventeen_excerpt_more( $link ) {
    if ( is_admin() ) {
        return $link;
    }

    $link = sprintf(
        '<p class="link-more"><a href="%1$s" class="more-link">%2$s</a></p>',
        esc_url( get_permalink( get_the_ID() ) ),
        sprintf( __( 'Continue reading<span class="screen-reader-text"> "%s"</span>', 'twentyseventeen' ), get_the_title( get_the_ID() ) )
    );
    return ' &hellip; ' . $link;
}
add_filter( 'excerpt_more', 'twentyseventeen_excerpt_more' );

処理の流れ：

  1. WordPress が抜粋文を生成する
  2. 抜粋の末尾のリンク部分（$link）がフィルターに渡される
  3. twentyseventeen_excerpt_more() 関数でリンクを変更
  4. 変更されたリンクが返される

結果： デフォルトの「[...]」が「... Continue reading」に変わる

② フィルターフックの例

抜粋の文字数を変更

function my_excerpt_length( $length ) {
    return 50; // デフォルトは55文字
}
add_filter( 'excerpt_length', 'my_excerpt_length' );

投稿タイトルの前後に記号を追加

function my_the_title( $title ) {
    if ( is_single() && in_the_loop() ) {
        return '★ ' . $title . ' ★';
    }
    return $title;
}
add_filter( 'the_title', 'my_the_title' );
注意： この例は単なる説明用です。実際には条件をもっと細かく設定する必要があります。

主なフィルターフック一覧

フック名 変更対象 用途
the_title 投稿タイトル タイトルの表示を変更
the_content 投稿本文 本文の表示を変更
excerpt_length 抜粋の長さ 抜粋文字数を変更
excerpt_more 抜粋の末尾 「続きを読む」表示を変更

アクションとフィルターの違い

比較項目 アクションフック フィルターフック
目的 処理を追加 データを変更
戻り値 不要 必須（変更したデータを返す）
例 CSS読み込み、メニュー登録 タイトル変更、抜粋文字数変更
書き方 add_action( 'フック名', '関数名' ) add_filter( 'フック名', '関数名' )

フックを使う理由

❌ 直接テーマファイルを編集する問題点

<!-- header.phpに直接書く -->
<link rel="stylesheet" href="<?php echo get_template_directory_uri(); ?>/custom.css">

問題：

  • テーマを更新すると変更が消える
  • プラグインと競合する可能性

✅ フックを使う利点

// functions.phpに書く
function my_custom_styles() {
    wp_enqueue_style( 'custom-style', get_template_directory_uri() . '/custom.css' );
}
add_action( 'wp_enqueue_scripts', 'my_custom_styles' );

利点：

  • テーマファイルを直接編集しない
  • 適切なタイミングで処理が実行される
  • プラグインとの競合が少ない
  • WordPressの仕組みに沿った安全な方法

子テーマを使う場合：

  • フックを使えば、子テーマのfunctions.phpだけでカスタマイズできる
  • テンプレートファイルの上書きが不要になることも多い
  • 管理がとても楽になる

コアフックとテーマ独自フック

フックにはWordPressコアが用意しているフックとテーマやプラグインが独自に用意しているフックの2種類があります。

コアフック

WordPress本体が用意しているフックで、どのテーマ・プラグインでも使用できます。

// WordPressコアが用意しているフック
add_action( 'wp_head', 'my_function' );
add_action( 'wp_footer', 'my_function' );
add_action( 'init', 'my_function' );
add_filter( 'the_title', 'my_function' );
add_filter( 'the_content', 'my_function' );

テーマ独自フック

特定のテーマが独自に用意しているフックで、そのテーマでしか使用できません。

// Twenty Seventeen が独自に用意しているフック
apply_filters( 'twentyseventeen_custom_colors_css', $css );
見分け方：
  • コアフック：プレフィックス（接頭語）なし、または wp_ で始まる
  • テーマ独自フック：テーマ名がプレフィックスになっている（例：twentyseventeen_）
  • プラグイン独自フック：プラグイン名がプレフィックスになっている（例：woocommerce_）

コアフックのリファレンス

WordPressコアのフックは公式ドキュメントで確認できます：

📚 公式リファレンス：
  • WordPress Developer Resources - Hooks - すべてのコアフックの一覧（検索可能）

テーマ独自フックの見つけ方

テーマやプラグインが独自に用意しているフックを見つけるには：

  1. テーマのコードを検索
    • VS Codeなどで do_action( や apply_filters( を検索
    • テーマ名がプレフィックスになっているものが独自フック
  2. テーマのドキュメントを確認
    • 有料テーマは独自フックのドキュメントを用意していることが多い
  3. ソースコードを読む
    • Twenty Seventeenの場合、template-parts フォルダ内のファイルを確認

まとめ

フックの基本

アクションフック = 決まったタイミングで処理を追加 ↓ add_action( 'タイミング', '実行する関数' ); フィルターフック = データを受け取って変更して返す ↓ add_filter( '変更対象', '変更する関数' );

Twenty Seventeenで見たフック

すでに見たコードの意味が分かりましたね：

// メニューを登録 = after_setup_themeのタイミングで実行
add_action( 'after_setup_theme', 'twentyseventeen_setup' );

// ウィジェットエリアを登録 = widgets_initのタイミングで実行
add_action( 'widgets_init', 'twentyseventeen_widgets_init' );

// CSS/JSを読み込む = wp_enqueue_scriptsのタイミングで実行
add_action( 'wp_enqueue_scripts', 'twentyseventeen_scripts' );

// 抜粋の末尾を変更 = excerpt_moreの内容を変更
add_filter( 'excerpt_more', 'twentyseventeen_excerpt_more' );
ポイント：
  • フックを使えば、テーマファイルを直接編集せずに機能を追加・変更できる
  • 子テーマのfunctions.phpでフックを使えば、テンプレートファイルの上書きが不要になることが多い
  • WordPressが推奨する安全なカスタマイズ方法
  • functions.php でフックを使って機能を追加するのが基本
