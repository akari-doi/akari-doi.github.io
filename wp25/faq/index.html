WordPress Q&A

サイトを作った際にアニメーションなどをつけれますか？

はい、つけられます！

WordPressサイトにアニメーションを追加する方法は主に2つあります。

方法1：JavaScriptを使ってアニメーションをつける

これまでに学習した wp_enqueue_script() を使って、JavaScriptファイルを読み込み、アニメーションを実装できます。

手順：

1. JavaScriptファイルを作成

テーマフォルダ内に js/animation.js というファイルを作成します。

// animation.js の例（vanilla JavaScript）
document.addEventListener('DOMContentLoaded', function() {
    // スクロールで要素をフェードイン
    const elements = document.querySelectorAll('.fade-in');
    
    const observer = new IntersectionObserver((entries) => {
        entries.forEach(entry => {
            if (entry.isIntersecting) {
                entry.target.classList.add('active');
            }
        });
    });
    
    elements.forEach(element => {
        observer.observe(element);
    });
});
💡 jQueryを使う場合
WordPressでjQueryを使う場合は、特殊な書き方が必要です。通常の $ は使えないため、以下のように記述します。 
// jQueryを使う場合
jQuery(function($) {
    // この中では $ が使える
    $('.fade-in').on('click', function() {
        $(this).addClass('active');
    });
});

2. functions.phpでJavaScriptを読み込む

function my_enqueue_scripts() {
    // JavaScriptファイルを読み込む
    wp_enqueue_script(
        'my-animation',                              // ハンドル名
        get_stylesheet_directory_uri() . '/js/animation.js',  // ファイルのパス
        array(),                                     // 依存関係（jQueryに依存する場合はarray('jquery')）
        '1.0.0',                                     // バージョン
        true                                         // フッターで読み込む
    );
}
add_action('wp_enqueue_scripts', 'my_enqueue_scripts');

📖 公式ドキュメント：wp_enqueue_script()

3. CSSでアニメーションのスタイルを定義

/* style.cssに追加 */
.fade-in {
    opacity: 0;
    transform: translateY(30px);
    transition: opacity 0.6s ease, transform 0.6s ease;
}

.fade-in.active {
    opacity: 1;
    transform: translateY(0);
}

4. HTMLでクラスを指定

<div class="fade-in">
    <h2>スクロールするとフェードインします</h2>
</div>
💡 ポイント
このように、wp_enqueue_script()を使えば、独自のJavaScriptを安全に読み込んでアニメーションを実装できます。

方法2：プラグインを使う（もっと簡単！）

コードを書かなくても、プラグインを使えばブロックごとに簡単にアニメーションをつけられます。

Blocks Animation

  • ブロックエディタの各ブロックに簡単にアニメーションを追加
  • フェードイン、スライドイン、ズームなど様々なアニメーション効果
  • 管理画面から直感的に設定可能

WordPressでサイトを作るとなったときにどのような手順で作成を進めていくのでしょうか。

WordPressサイト作成の手順をざっくり解説します

大きく分けると、「①〜③(要件定義・機能面・運用面)の検討 → ワイヤーフレーム作成 → デザイナーへ共有 → ④デザイン・構築 → ⑤テスト・公開」という流れで進めます。①〜③は順番に1つずつ決めるというより、並行して詰めていくイメージです。

① ヒアリング・要件定義

  • サイトの目的、ターゲットを確認
  • 必要なページ(コンテンツ)の洗い出し
  • 必要な機能の洗い出し(問い合わせフォーム、予約、会員機能、ECなど)
  • 予算・工数から、テーマの方針(既存テーマ/子テーマ/フルスクラッチ)を検討
  • そもそもWordPressを使うかどうか自体も、この段階で検討

② 機能に応じたプラグインの選定

  • ①で洗い出した機能ひとつひとつに対して、それを実現するプラグインを検討・選定する
  • (例:問い合わせ機能 → Contact Form 7、SEO対策 → SEO系プラグイン、など)

③ 運用範囲の設計(ブロックエディタでどこまで触れるようにするか)

  • 納品後、お客さん自身がどこまで更新・編集できるようにするかを、この段階で決める
  • 「文章や画像の差し替えだけ」なのか、「レイアウトごと自由に組み替えられる」ようにするのかを決める
💡 なぜ構築より前に決めるのか
デザインが複雑すぎると、お客様がブロックエディタで自由に編集することが難しくなり、結果的に「直コーディング(ブロックエディタでは組めないデザインをコードで実装すること)」になりやすいためです。運用範囲を先に決めておくことで、デザインの作り方(ブロックの制限、パターンの用意など)を最初から逆算して設計できます。

ワイヤーフレーム作成 → デザイナーへ共有

  • ①〜③で固まった内容をもとに、ワイヤーフレームを作成
  • デザイナーには、見た目の要望だけでなく機能面も説明できる状態で渡すのが理想

④ デザイン・構築

  • ワイヤーフレームをもとに、デザインを制作
  • デザインが固まったら、テーマ(①〜③で決めた方針)としてコーディング・実装
  • ②で選んだプラグインを組み込む
  • テキストや画像などのコンテンツを流し込む

⑤ テスト・公開

  • 表示崩れやリンク切れ、フォームの動作などを確認
  • 問題がなければ本番サーバーへ公開
